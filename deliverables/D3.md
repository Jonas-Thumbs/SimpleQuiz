# D.3 Analysis

## 1. System Description
The problem of overly complicated and poorly organized online quiz creation and management affects teachers who create quizzes and students who use them for studying. Teachers spend unnecessary time creating, organizing, and reusing quiz content, while students receive limited feedback and experience accessibility and usability problems across devices. SimpleQuiz is an online quiz platform designed for teachers and students who want a simpler alternative to complicated quiz tools in learning management systems. Its value proposition is to simplify quiz creation and reuse for teachers while providing students with an accessible, student-focused experience across devices, reviewable answers, and clear feedback to support their learning.

The conceptual model shown in the class diagram captures the full quiz-delivery and assessment domain of the system. On the left side, **Teacher** and **Student** are the central user entities. A **Teacher** ***teaches*** a **Class** and ***creates*** one or more **Quiz** objects, while a **Student** stores identifying information as *studentID*, *name*, and *email* and ***submits*** zero or more **QuizResponse** objects. A student ***is enrolled in*** a **Class**, which stores course metadata such as *className*, *sectionCode*, and *semester*. Each **QuizResponse** records the student’s score using the attribute *totalPointsEarned* and represents an entire assessment attempt that groups together the student’s answers for each question in the submission through the association **QuizResponse** ***contains*** **QuizQuestionAnswer**.

On the right side of the diagram, the quiz structure is modeled as a set of classes that organize how assessments are created and delivered. A **Quiz** is associated with a **Class** and stores attributes such as *availableFrom*, *dueDate*, *allowedAttempts*, and *showFeedbackImmediately*. Each **Quiz** ***contains*** zero or more **QuizQuestion** objects, which are modeled as an abstract class because questions can take different forms. The subclasses **FreeTextQuestion**, **MultipleChoiceQuestion**, and **TrueFalseQuestion** capture the different question types in the system, each with attributes such as *gradingCriteria*, *choices*, *correctAnswer*, and *explanation*. The abstract **QuizQuestionAnswer** class represents the student’s answer to a question, and it is specialized into **FreeTextQuestionAnswer**, **MultipleChoiceQuestionAnswer**, and **TrueFalseQuestionAnswer** based on the specific question type. These answer classes record the student’s response, whether the answer was correct, and the points earned for that question.

Together, these classes and relationships describe a consistent domain model: **Teacher** objects teach classes and create quizzes, **Student** objects enroll in classes and submit quiz attempts, **Quiz** objects organize questions, and **QuizQuestionAnswer** objects evaluate student performance. This design supports the project use cases for authentication, quiz creation, quiz completion, grading, and feedback review, while also reflecting the value proposition of SimpleQuiz as a clear, organized assessment system.
