# D.3 Analysis

## 1. System Description
Teachers need an efficient way to create, organize and manage quizzes while students need a secure and accessible way to take quizzes and see their results. SimpleQuiz is an online quiz platform that is designed for teachers and students who want a simple alternative to more complicated quiz applications in learning management systems. Its value proposition is to improve quiz creation and management for teachers while allowing students to complete quizzes, save their progress, and receive feedback to support their learning.

The conceptual model shown in the class diagram captures the full quiz-delivery and assessment domain of the system. On the left side, **Student** is the primary user entity and stores identifying information as *studentID*, *name*, and *email*. A student is enrolled in a **Class**, which stores course metadata such as *className*, *sectionCode*, and *semester*. A student can *submit* zero or more **QuizResponse** objects, and each response records the student’s score using the attribute *totalPointsEarned*. A **QuizResponse** represents an entire assessment attempt and groups together the student’s question-level answers through the association **QuizResponse** *contains* **QuizQuestionAnswer**.

On the right side of the diagram, the quiz structure is modeled as a set of classes that organize how assessments are created and delivered. A **Quiz** is associated with a **Class** and stores attributes such as *availableFrom*, *dueDate*, *allowedAttempts*, and *showFeedbackImmediately*. Each quiz *contains* zero or more **QuizQuestion** objects, which are modeled as an abstract class because questions can take different forms. The subclasses **FreeTextQuestion**, **MultipleChoiceQuestion**, and **TrueFalseQuestion** capture the different question types in the system, each with the appropriate attributes such as *gradingCriteria*, *choices*, *correctAnswer*, or *explanation*. The abstract **QuizQuestionAnswer** class represents the student’s answer to a question, and it is specialized into **FreeTextQuestionAnswer**, **MultipleChoiceQuestionAnswer**, and **TrueFalseQuestionAnswer** based on the specific question type. These answer classes record the student’s response, whether the answer was correct, and the points earned for that question.

Together, these classes and relationships describe a consistent domain model: students enroll in classes, quizzes are available within those classes, questions are structured within each quiz, and student submissions are evaluated through question-specific answer objects. This design supports the project use cases for authentication, quiz creation, quiz completion, grading, and feedback review, while also reflecting the value proposition of SimpleQuiz as a clear, organized assessment system.
