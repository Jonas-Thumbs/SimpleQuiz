## 6. Deployment

Our application is available publicly via the URL
[https://simple-quiz.duckdns.org](https://simple-quiz.duckdns.org).

We launched an Amazon EC2 instance (`t3.micro` running Ubuntu) using the AWS Free Tier. Nginx was configured as a reverse proxy. We set up our domain on DuckDNS to map to the EC2 public IP address. An HTTPS certificate was obtained using the Let's Encrypt Certbot.

AWS was chosen as a platform because it is reliable, provides a 183-days Free Tier, and allows us host both the front-end and the back-end on a single server.
